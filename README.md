# Capri downloads

Capri is a fast, good-looking task app that works with your Todoist account or on its own.

**[Download the latest version](https://github.com/Unblonded/capri-dl/releases/latest)**, or pick one at **[capritasks.xyz/downloads](https://capritasks.xyz/downloads)**.

| | File |
|---|---|
| Windows | `Capri-Setup-<version>.exe` installs and updates itself. `Capri-Portable-<version>.exe` runs without installing. |
| Mac | `Capri-<version>-mac-arm64.dmg` for Apple Silicon, `Capri-<version>-mac-x64.dmg` for Intel. The first time, right-click Capri in Applications and choose **Open**, then **Open** again. |
| Android | `Capri-<version>-android.apk`. Open it on your phone, and allow installs from your browser when Android asks. |
| iPhone | No download needed: open [capritasks.xyz](https://capritasks.xyz) in Safari, tap Share, then **Add to Home Screen**. |

Every earlier version is under [Releases](https://github.com/Unblonded/capri-dl/releases). This repository only holds the downloads; it's kept in step automatically.
